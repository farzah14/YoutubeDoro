# Theme asset sources

## Active original artwork

The active `.webp` scenes are the Modern Japanese Studio collection: original generated artwork created on 2026-08-29 with the built-in `image_gen` tool in generate mode, using one distinct scene substitution per asset. Each result was visually inspected, then converted or retained as an exact 1586x992 WebP larger than 50KB. The shared prompt required hand-painted mature anime environments with no people, faces, character silhouettes, text, lettering, logos, watermarks, UI, franchise references, neon, cyberpunk, glossy game rendering, or copied art; compositions keep the timer area low-detail and readable. The Open Sky entry intentionally retains the `cherry-dawn` asset ID so saved theme preferences remain valid. Generated artwork is not attributed to the legacy photographers below.
